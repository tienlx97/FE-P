# Refresh workspace colors

## Why
The user finds the current white/black interface monotonous. Gray table
headers do not provide enough visual hierarchy for dense logistics data.

## Scope
One shared-theme task: introduce a coordinated DN Group teal surface palette,
colored table headers (including nested tables), white table bodies, and
clear selected tabs. Keep existing typography, density, layouts and behavior.

## Design
Palette: logo teal #247768, deep teal #18594e, header mint #dceee8,
canvas #f3f8f6, hover wash #edf5f1, white #ffffff. Existing Optimistic Display
headings and Optimistic Text Vietnamese body remain; Source Code Pro serves
code. The signature is a continuous mint column-heading band above white data
rows. Layout remains toolbar → colored header → rows → pagination.
Compared with a dark header, mint preserves quiet nested tables and existing
sort/filter icon contrast. Status colors retain their existing meanings.
