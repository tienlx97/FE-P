# Meta giao diện cho sao lưu & khôi phục

Trang `/admin/backups` dùng cùng ngôn ngữ giao diện Meta với các trang
Logistics: tiêu đề, trạng thái vận hành và danh sách bản sao lưu. Các thao tác
nhập/xuất, tải lên và khôi phục mở trong drawer để giữ ngữ cảnh danh sách.
Chuyển các form "Xác nhận mốc" và "Cập nhật lịch tàu" trong hành trình shipment
sang drawer rồi đồng bộ tài liệu. Lưu hướng dẫn đăng nhập phát triển ở file
cục bộ được Git bỏ qua.
