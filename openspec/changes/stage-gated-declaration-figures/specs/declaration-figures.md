# Declaration figures (FE)

- Status Booked/Packing: the four figures may be empty (sent null); from
  AtYardAwaitingExport each is required ("Bắt buộc từ Hạ bãi chờ xuất"),
  any given value must be > 0.
- A missing figure renders "—", never 0 or "null"; VNĐ values of a shipment
  without rate render "—".
- Contract and shipment lists/panels sum VNĐ only over rated shipments and
  say how many were left out.
