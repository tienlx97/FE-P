# Bulk container entry and fee quick add

Operators need to add many containers without opening one form per row. They can type rows in a review table or import an Excel file, correct rows, and save one validated batch. The logistics cost drawer also needs a shortcut to add a new recommended fee name to the selected LOG group and use it immediately.

Bulk entry records container identity, type, optional seal and packing date. VGM weights remain editable through the existing per-container form. Excel uses a downloadable template with those columns. Invalid/duplicate rows block the batch; no partial inserts.
